## STEP 0 — Scout the business (before clone)

Use Axiom Scout. Do not start a client repo until you have a `business.ts` packet.

1. Open Scout (Vercel URL for this repo)
2. Pick niche → enter city → **Search businesses**
3. Click the shop → wait for enrich
4. If verdict is `skip` (they already have an AI front desk), do not build a demo
5. **Copy business.ts** — paste over `src/config/business.ts` in a clone of axiom-business-template
6. Drop photos into `public/business/` (hero + each service). Do not commit scraped photos as originals.

Then: Use this template on axiom-business-template → new repo named after the shop → paste → deploy → walk in.
